Multi-Agent Orchestration Platform

An enterprise-grade, stateful Multi-Agent AI system powered by LangGraph, Google Gemini / LangChain LLMs, Chroma Vector DB, and EasyOCR Deep Learning.

💡

Production Ready Architecture

This backend orchestrates independent specialized agents (Coder, Researcher, RAG Specialist, Vision Inspector, Math & Logic) behind a unified intent classification router with streaming response capabilities.

⚡

LangGraph State Machine

Deterministic cyclical and branching agent graphs with thread checkpoints, memory rewind, and Human-In-The-Loop support.

🧠

Intelligent Intent Router

Zero-latency semantic dispatch classifying queries into Math, Coding, RAG search, Vision OCR, or General reasoning.

📚

Contextual RAG Pipeline

Chunking, embedding, and vector storage for uploaded PDFs and documentation with citations and score filtering.

👁️

Deep Learning Vision OCR

Multi-language EasyOCR inference for extracting text from document scans, receipts, handwriting, and photos with confidence scoring.

Quickstart & Setup

Get the backend and frontend up and running locally in under 3 minutes.

1. Environment Configuration

Create a .env file in the backend/ directory:

backend/.env 
PROJECT_NAME="Multi-Agent System"
VERSION="1.2.0"
API_V1_STR="/api/v1"

# LLM Providers
GOOGLE_API_KEY="your-gemini-api-key"
OPENAI_API_KEY="your-openai-api-key"

# Database
MONGO_URI="mongodb://localhost:27017/multiagent"
CHROMA_PERSIST_DIR="./chroma_db"

2. Run Backend & Frontend

# 1. Start FastAPI Backend (Port 8990)
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python server.py

# 2. Start Frontend Dev Server (Port 5173)
cd ../frontend
npm install
npm run dev

System Architecture

The system utilizes a hierarchical supervisor-worker pattern combined with directed cyclic graphs (DAGs) in LangGraph.

flowchart TD
    User([User Request]) --> Router{Semantic Intent Router}
    Router -->|Code Generation| AgentCode[Coder Agent]
    Router -->|Document Search| AgentRAG[RAG Retrieval Agent]
    Router -->|Vision / Image| AgentOCR[EasyOCR Vision Agent]
    Router -->|Complex Workflow| LangGraphWorkflow[LangGraph Supervisor Graph]
    
    AgentRAG --> ChromaDB[(Chroma Vector DB)]
    AgentOCR --> EasyOCREngine[PyTorch Vision Engine]
    LangGraphWorkflow --> MongoDB[(MongoDB Session State)]
    
    AgentCode --> StreamEngine[SSE Streaming Response]
    AgentRAG --> StreamEngine
    AgentOCR --> StreamEngine
    LangGraphWorkflow --> StreamEngine
    StreamEngine --> WebApp([Frontend Workspace UI])

LangGraph Workflow Engine

The LangGraph module provides stateful orchestration with persistent checkpoints stored in MongoDB. It handles multi-step reasoning, evaluator-optimizer loops, and tool execution.

Core State Schema

Python TypedDict State 
from typing import TypedDict, Annotated, Sequence
from langchain_core.messages import BaseMessage
import operator

class AgentGraphState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], operator.add]
    intent: str
    context_documents: list[str]
    current_agent: str
    iterations: int

Intelligent Intent Router

The Semantic Router analyzes incoming user queries using lightweight embedding classification and few-shot reasoning to delegate to the best specialized subagent.

Intent Class Target Subagent Specialized Tools
code Coding & Debugging Agent Code generation, Refactoring, Linter
rag Document Knowledge Agent Vector Similarity, Chunk Summarization
vision_ocr Vision AI & OCR Agent EasyOCR, Bounding Box Detectors
web_search Live Web Researcher Search API, Real-time Information
general Conversational Supervisor Context Memory, Persona Styling

RAG & Vector Knowledge Base

Retrieval-Augmented Generation ingests PDFs, parses structured text, generates dense vector embeddings using Google Generative AI / HuggingFace, and performs semantic retrieval.

Vision OCR Deep Learning Engine Beta

The OCR subsystem provides automated optical character recognition utilizing PyTorch and EasyOCR across 80+ supported languages.

ℹ️

GPU & CPU Acceleration

EasyOCR auto-detects CUDA availability for GPU hardware acceleration while falling back gracefully to multi-threaded CPU inference.

State & MongoDB Persistence

All conversation threads, token counts, and LangGraph checkpoints persist automatically in MongoDB, enabling resuming chats across browser restarts.

REST API Reference

POST /api/v1/chat

Send a message to the Multi-Agent router with persistent conversation session tracking.

Field Type Required Description
message string Yes The user message or query.
conversation_id string No Unique session UUID. Auto-generated if omitted. 
curl -X POST "http://localhost:8990/api/v1/chat" \
     -H "Content-Type: application/json" \
     -d '{"message": "Explain quantum computing in simple terms", "conversation_id": "test-123"}'

POST /api/v1/router/execute

Directly query the Semantic Intent Classifier without executing full agent loops.

POST /api/v1/langgraph/chat

Execute structured cyclic graph workflows with intermediate state tracking.

POST /api/v1/rag/query

Semantic vector search across indexed documents.

POST /api/v1/ocr/extract

Upload a multipart image file (PNG, JPG, WEBP) to receive extracted text and confidence scores.

GET /health

Diagnostics and readiness probe for MongoDB connection and service health.

Client SDKs & Integration

Python Integration

client.py 
import requests

BASE_URL = "http://localhost:8990/api/v1"

def send_chat(message: str, session_id: str = "python-client"):
    response = requests.post(
        f"{BASE_URL}/chat",
        json={"message": message, "conversation_id": session_id}
    )
    return response.json()

if __name__ == "__main__":
    res = send_chat("Generate a binary search algorithm in Python")
    print(res["response"])
